# Proyecto Hackathon - Meta Global AI 2026

**Track:** Indie developer - Build for Your World
**Tema:** Asistente de planeaciones didácticas para lactantes y maternal
**Stack:** Llama Spark, Llama Image, SAM 3.1 via api.meta.ai/v1

## Objetivo
Foto del salón -> SAM 3.1 detecta materiales -> Spark genera planeación de 3 actividades SEP -> Image genera ficha visual.

## Evaluación indie
- Creatividad: problema real que conozco
- Ambición técnica: uso de 3 modelos Meta nativos
- Que funcione: demo de 2 min

## Reglas
- Todo via api.meta.ai/v1
- MODEL_API_KEY en .env, nunca en repo
- Commits pequeños
